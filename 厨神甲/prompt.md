## 出多少

至少这么多，多一些也可以（多出来的会被轮着用）：

| 类别 | 至少 |
| :-- | :-- |
| 汤（咸汤） | 5 个 |
| 菜 | 8 个 |
| 主食 | 2 个，其中至少一个是米饭 |
| 饮 | 4 个（参数单要饮时才出） |

每一道汤、菜、主食都要写 `meals`：适合午餐写 `["午"]`，适合晚餐写 `["晚"]`，两餐都行写 `["午","晚"]`。
汤只在晚餐用；菜和主食要能同时供午、晚排。

## 挑的时候守这些

1. 只能用上面本草表里的料，本草表里没有的料一律不能用，料的 id 不能自己编。写完一道菜，再回头逐个料对一遍本草表。
2. 参数单里任何一个人的体质，碰到某味料的 `unsuits`，这味料就不用；任何一个人的 `avoid` 碰到某味料（名字、别名、味或 id），这味料也不用。
3. 同一道菜里不要放互相 `clashes_with` 的料。
4. 照顾体质：有人阴虚、热的，少用温燥的料，少煎炸，多用蒸、煲、炖。
5. 照顾年龄：有高龄或幼儿的，做得软烂，少油少盐。
6. 不时不食：`season` 写了当令季节的，按参数单的季节优先挑。
7. 广东路子：汤要够一家人晚餐一天一个的量。
8. **汤只出咸汤**：汤里要有肉、骨、鱼、蛋、豆腐或菜这类主料。**糖水、茶不算汤**——雪梨银耳糖水、罗汉果茶这类只能放进 `drinks`，不能写成 `"kind": "汤"`。
9. **早餐、晚餐的主食**：菜池里至少有一个米饭（大米煮的饭，比如“米饭”“玉米饭”）。晚餐优先米饭。
10. **换着用不同的料**：同一味料一周最多出现在 3 天里（米面、调料不算），所以别让雪梨、银耳、猪肉这类料出现在太多道菜里；一类料多出几个不同的搭配。雪梨、苹果这类水果别当汤，也别天天进饮。
11. **晚餐不放生姜**：汤和菜里带生姜的，只能写 `["午"]`，不要标成能上晚餐。
12. **菜名要老实**：菜名里只能出现料里有的东西。比如料里只有蜂蜜和雪梨，就不能叫“蜂蜜柠檬水”（没有柠檬）；名字里提到哪味料（**包括别名，比如薏米、红枣、淮山、瘦肉、白菜**），`ingredients` 里就得有哪味料。**别写“蒜蓉”“姜葱”“葱油”这类带调味料的名字**，因为蒜、姜、葱可能正好在禁用单里；写成“清炒菜心”“清蒸鱼”就行。
13. **做法和法对得上**：`steps` 里写到“煎”“炸”“焗”的，`method` 就必须是同一个法。比如做法是“鲫鱼煎至微黄”再煲，`method` 要写“煎”；要写成“煲”，做法里就别写“煎”，写“焯水后同煲”。
14. **同一池里菜名不要重复**：每个名字只出现一次，代码按名字轮着排。
15. 不写病名，不说治什么病，只说养什么、润什么、补什么。
16. 饮要写料，每天一壶，所以池里至少四种，名字和料对得上。

## 可以整个照用一个方

本草表最后的方（比如雪梨银耳糖水、罗汉果茶）可以整个照用，写法是：

```
{"recipe": "方的 id", "kind": "汤", "method": "炖", "steps": "一句做法", "why": "一句为什么", "meals": ["晚"]}
```

用了 `recipe` 就不用再写 `ingredients` 和 `name`，代码会按方的配料展开、按人数算量，`sources` 自动写方的 id。
照方做汤时，只挑咸汤的方（比如莲子百合瘦肉汤、西洋菜猪骨汤）；糖水、茶只放进 `drinks`。

```
    }
  ]
}
```
