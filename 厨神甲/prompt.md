## 挑的时候守这些

1. 只能用上面本草表里的料，本草表里没有的料一律不能用，料的 id 不能自己编。写完一道菜，再回头逐个料对一遍本草表。
2. 参数单里任何一个人的体质，碰到某味料的 `unsuits`，这味料就不用；任何一个人的 `avoid` 碰到某味料（名字、味或 id），这味料也不用。
3. 同一道菜里不要放互相 `clashes_with` 的料。
4. 照顾体质：有人阴虚、热的，少用温燥的料，少煎炸，多用蒸、煲、炖。
5. 照顾年龄：有高龄或幼儿的，做得软烂，少油少盐。
6. 不时不食：`season` 写了当令季节的，按参数单的季节优先用。
7. 广东路子：每天晚餐有一个汤；午餐有主食（粥、饭、面）和菜。
8. 天时：晚餐不用生姜。
9. 三个方案的思路要不一样。一周之内同一道菜或同一壶饮最多出现两次；米饭、粥这类单纯的主食不算重复。
   - **最省事的做法：28 个菜名全都不同**（7 天 × 午晚各 2 道菜），这样一定不会超。
   - **饮**：7 壶饮里至少有 4 种，每种最多两次。可以照下面几种配，也可以自己配，名字和料对得上就行：
     - 雪梨银耳糖水（xueli、yiner、bingtang）
     - 罗汉果茶（luohanguo）
     - 蜂蜜水（fengmi）
     - 雪梨蜂蜜饮（xueli、fengmi）
     - 银耳罗汉果饮（yiner、luohanguo）
     - 罗汉果蜂蜜饮（luohanguo、fengmi）
10. 不写病名，不说治什么病，只说养什么、润什么、补什么。
11. 每餐几道：午餐 = 1 道主食（主食或粥）+ 1 到 2 道菜；晚餐 = 1 个汤 + 1 到 2 道菜 + 1 道主食。午餐不放汤。
12. **菜名要老实**：菜名里只能出现料里有的东西。比如料里只有蜂蜜和雪梨，就不能叫“蜂蜜柠檬水”（没有柠檬）；名字里提到哪味料，`ingredients` 里就得有哪味料。**别写“蒜蓉”“姜葱”“葱油”这类带调味料的名字**，因为蒜、姜、葱可能正好在禁用单里；写成“清炒菜心”“清蒸鱼”就行。
13. 每天一壶饮，饮要写料。
14. 输出前自己查两遍：①同一道菜、同一壶饮是不是超过两次；②菜名里提到的每一味料，`ingredients` 里是不是都有。
15. **先打草稿再写 JSON**：先把 7 天的菜名、饮名按天列成一张表，数一遍每种出现几次；超过两次的当场换成别的，再按这张表写 JSON。一周 28 个菜位、7 个饮位，换着来，别懒。

## 可以整个照用一个方

本草表最后的方（比如雪梨银耳糖水、罗汉果茶）可以整个照用，写法是：

```
{"recipe": "方的 id", "method": "炖", "when": "午后", "why": "一句为什么"}
```

用了 `recipe` 就不用再写 `ingredients` 和 `name`，代码会按方的配料展开、按人数算量，`sources` 自动写方的 id。
不照方做的菜和饮，照常写 `ingredients`。

## 输出格式

只输出一个 JSON 对象，不要别的话，不要用代码块包起来。格式：

```
{
  "idea": "一句话说这套的思路",
  "days": [
    {
      "day": 1,
      "meals": [
        {
          "meal": "午",
          "dishes": [
            {
              "name": "菜名",
              "kind": "汤、菜、主食、粥、点心，五选一",
              "ingredients": ["本草 id", "本草 id"],
              "method": "煎、炒、焖、炸、焗、蒸、煮、煲、炖、泡、生食，选一个",
              "steps": "一句做法",
              "why": "一句为什么"
            }
          ]
        }
      ],
      "drinks": [
        {
          "name": "饮名",
          "ingredients": ["本草 id", "本草 id"],
          "method": "泡、煮、炖，选一个",
          "when": "午后",
          "why": "一句为什么"
        }
      ]
    }
  ]
}
```

天数、餐数照参数单的 `range` 来；要饮的，每天都要有一壶饮。每道菜、每壶饮都要有料。
