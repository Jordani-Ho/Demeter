# 食纲

## 一、为了什么

- **为身**：养。
- **为心**：团聚、乐趣、文化。

**食的根是“吃对”**，而不是挑自己喜欢吃的。病从口入，吃错了就不健康。所以食圈的核心是食疗；吃得开心、去哪里吃，都排在它后面。食也包括饮：汤水、茶饮。

食是四个圈里离健康最近、决定次数最多的一个：每天三次。

## 二、三个角色

| 角色 | 是什么 | 谁提供 |
| :-- | :-- | :-- |
| **本草库** | 公共知识库：食材和药食同源之物的性味、功用，以及古今的食疗方。例如《神农本草经》《本草纲目》、食疗书、名家讲解整理出来的知识 | 社区的基础设施之一；别人也可以提供 |
| **厨神**（老师） | 用本草库，按学生交来的参数，给出两三个搭配方案：煲什么汤、配什么菜、用量多少 | 平台提供厨神甲、厨神乙、厨神丙……；真人大厨也可以做自己的厨神；可以是独立的智能体，也可以是一项技能 |
| **食神**（我的智能体） | 带着我的参数去向厨神学；从方案里替我定下一个；再去换，也就是买 | 谁想要才生给谁。照看谁、把家里哪些人记进本人库，由主人自己定，不强求 |

**方案要有料、量、法。** 同样一样东西，做法不同（蒸、煲、炖、煎、炸……），性就不同；所以方案里不只有吃什么、吃多少，还有怎么做，食谱之外还有饮谱。

**厨神不开方子，也不诊断。** 它只用食材和药食同源之物；体质的判断来自“医”，厨神只接收这个参数。

## 三、食神自己的知识库：本人库

- 里面放的是我和家人的身体情况：体质、口味、忌口、老人和孩子的情况、最近的状态。
- 这些都会变。**由食神自己随时修改，而不是由真人去填表。**
- 交给厨神的只是这些参数，不是本人库本身。

## 四、学：没有考试，也没有回音

- 吃完以后感觉怎样，自己知道，不需要回传给厨神，也不需要考试。
- 觉得有用，就坚持；觉得没用，就换一位厨神。**找哪位厨神，是食神自己的事。**
- 主人的点赞、收藏只留给食神自己，让它越来越懂主人；厨神看不到这些数，也不设排行。转发是人与人之间的分享，可以有。
- 所以厨神之间不必争输赢：哪位教得对路，自然有人一直跟着学。

## 五、换：一张买菜的地图

方案定了，换就好办了。食神要知道三件事：

| 要知道的 | 例如 |
| :-- | :-- |
| 去哪里买 | 哪家市场、哪家店、哪位农户 |
| 买什么样的 | 产地、新鲜程度、品质 |
| 多少钱 | 价格 |

- 这些都落在雾中地图的食层上。
- **怎么选材，是食神要学的本事**：同样一味料，在哪里买、挑什么样的，食神会越做越懂。
- 卖的一方也有自己的智能体，两边的智能体直接谈。

## 六、食的律

食和现实有接口（吃进身体的东西、买菜的钱），所以食的律在这里定：

1. 替主人定下一个，不给一堆选择。厨神给两三个方案，食神只给一个。
2. 厨神不诊断，不开方子；只用食材和药食同源之物，体质是参数。
3. 交给厨神的只有参数；本人库留在主人手里。
4. 别的圈子的信息传进来，第一次要主人同意。
5. 不经手钱和货，只指路。
6. 下单、付钱由主人自己确认；食神可以起草，不能代签。
7. 不冒充任何人。

## 七、关系六格

| | 学 | 换 |
| :-- | :-- | :-- |
| **人与人** | 食神向厨神学；向长辈学做菜 | 买食材、下馆子 |
| **人与天地** | 不时不食：吃当地当季的东西 | 种地、养殖，用劳动换收成 |
| **人与自己** | 吃完以后身体的反应就是老师 | 用自律换健康；口福和身体之间的取舍 |

## 八、天地人

| | 参数 |
| :-- | :-- |
| 天 | 节气（什么当令）、时辰（三餐的时间）、天气 |
| 地 | 当地物产、水土、市场 |
| 人 | 本人库：体质、口味、家人、忌口 |

## 九、三条流

| 流 | 在食圈 |
| :-- | :-- |
| 信息流 | 参数交给厨神 → 两三个方案 → 食神定下一个 |
| 物流 | 食材从哪里来，到谁的厨房 |
| 资金流 | 买菜的钱 |

## 十、平衡与失衡

| 偏向失衡（深灰） | 偏向平衡（浅灰） |
| :-- | :-- |
| 暴饮暴食，往往是在释放压力 | 适量、按时 |
| 反季节，过度加工 | 当地、当季 |
| 浪费 | 五味调和，剩得少 |

## 十一、与其他圈子的关联

| 方向 | 内容 |
| :-- | :-- |
| 医 → 食 | 体质，写进本人库 |
| 住 → 食 | 屋子潮湿还是干燥，厨房是什么条件；冰箱、橱柜里有什么，哪些快到期了（宅神的收纳）。先用家里有的，再去买 |
| 行 → 食 | 换了地方，物产和时辰都变了 |
| 衣（形象）→ 医 | 气色也是身体的回应，吃得对不对会写在脸上 |

## 十二、能长出的产品（举例）

- 我的食神：每天定菜谱、定汤，定好再去买
- 厨神甲、乙、丙：平台的老师；大厨们自己的厨神
- 本草库
- 卖菜一方的智能体
